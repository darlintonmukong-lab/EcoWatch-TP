# 🌍 EcoWatch Pro : Plateforme de Collecte et d'Analyse Environnementale

## 📝 Présentation du Projet
**EcoWatch Pro** est une application de **science citoyenne** développée pour le TP d'inf 232. Elle permet aux utilisateurs de signaler en temps réel des incidents environnementaux (pollution plastique, décharges sauvages, etc.) dans la ville de Yaoundé afin de générer une **analyse descriptive** des données collectées.

## 🚀 Fonctionnalités "Premium"
- **Collecte Interactive** : Formulaire avec menus déroulants et sélection intelligente des quartiers de Yaoundé.
- **Analyse Descriptive en Temps Réel** : Visualisation automatique des données via des graphiques (Bar Charts) et calcul des moyennes de gravité.
- **Interface Pro** : Design optimisé avec colonnes, icônes et retour visuel (animations) lors de l'enregistrement.
- **Gestion des Données** : Persistance automatique dans un fichier CSV et option d'exportation pour l'utilisateur.

## 🛠️ Stack Technique
- **Langage** : Python 3.x
- **Interface** : Streamlit (Framework Web)
- **Traitement de données** : Pandas
- **Déploiement** : GitHub & Streamlit Cloud

## 📂 Structure des Fichiers
- `app.py` : Code source principal de l'application.
- `requirements.txt` : Dépendances nécessaires au fonctionnement en ligne.
- `data_collecte.csv` : Base de données générée par les signalements.
